A machine learning repository for the Big Data Challenge (BDC) Satria Data 2026, focused on multi-class waste image classification.
## Overview
The objective is to classify waste images into three distinct categories:
- `0_Recyclable`: Plastics, paper, cardboard, and recyclable items.
- `1_Electronic`: E-waste, electrical components, cables, and appliances.
- `2_Organic`: Food waste, plant materials, and biodegradable substances.
